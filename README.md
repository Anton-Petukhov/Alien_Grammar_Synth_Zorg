# Alien Grammar Synth — ZORG v14

**Версия ChatGPT / Codex · 2026.09.24 (Иркутск, UTC+8)**

Эту доработку подготовил ChatGPT / Codex по запросу Антона Петухова. Это сохранённая версия опубликованного синтезатора, в которой улучшены музыкальная форма и наследование.

[Открыть синтезатор](https://alien-grammar-synth.tosherr.chatgpt.site)

## Что изменено

- Единый ритм для мелодии, баса, аккордов и ударных.
- Композиция из 16 тактов: тема, ответ, развитие и возвращение.
- Популяция из 18 музыкантов сохраняется между веками; три субкультуры наследуют музыкальные идеи.
- Меняются ноты, ритмические рисунки, гармония, тембры и характер исполнения.
- Сравнение потомка с предыдущим композитором кнопкой «Сравнить с предком».
- Плавная по структуре смена поколения: новая партитура вступает с начала фразы.
- Сохраняются ползунок настроения, культурные скачки, вымирания, запись WAV и автопрогресс +100 лет за реальный час.
- Сохранения предыдущей версии переносятся автоматически. История хранится в браузере на конкретном устройстве; пропущенные часы обрабатываются при следующем запуске.

Эволюция работает как алгоритм отбора и мутаций. Оценки «слушателей», «фанатов» и «критиков» вычисляет модель правил; это не отзывы людей и не нейросеть, обученная на аудиозаписях.

## Проверка

Пять автоматических проверок пройдены: 2000 лет наследования, сохранения v2/v3, независимость эволюции от времени проигрывания, смена партитуры на границе фразы, устойчивое стереовоспроизведение и запись PCM/WAV. Сборка сайта выполнена успешно. Звучание проверено программно, субъективная оценка на слух остаётся за слушателем.

## Запуск

Требуется Node.js 22.13+ и npm.

```sh
npm ci
npm run dev
```

Синтезатор использует AudioWorklet: для звука нужен защищённый контекст HTTPS либо localhost. Обычный удалённый HTTP-адрес подходит только для просмотра интерфейса.

```sh
node --test tests/zorg-music.test.mjs
npm run build
```

Унаследованные скрипты установки и сборки рассчитаны на Linux и утилиты GNU; на Windows для них нужен WSL.

## Основные файлы

- `app/page.tsx` — интерфейс, управление воспроизведением, сохранение истории и WAV.
- `public/alien-processor.js` — популяция, отбор, наследование, мутации, перенос сохранений.
- `public/zorg-music.js` — музыкальная партитура и синтез звука.
- `tests/zorg-music.test.mjs` — проверки музыки и эволюции.
- `VERSION.json` — дата, авторство версии и исходный коммит.
