# Alien Grammar Synth — ZORG v15

**Версия ChatGPT / Codex · 2026.09.24 (Иркутск, UTC+8)**

Эту доработку подготовил ChatGPT / Codex по запросу Антона Петухова. Это сохранённая версия опубликованного синтезатора: v14 улучшила музыкальную форму и наследование, v15 переработала тембры и исполнение после отзыва о сходстве с 8-битной музыкой.

[Открыть синтезатор](https://alien-grammar-synth.tosherr.chatgpt.site)

## Новое в v15

- Новый движок резонансного синтеза без внешних сэмплов и дополнительных зависимостей.
- Дышащие голоса: спектр меняется внутри ноты, есть мягкие атаки, небольшие колебания высоты и плавные переходы.
- Резонансные струны с неравномерными обертонами; протяжные смычковые тона вместо частых коротких риффов.
- Мембранные и полые ударные, шорохи и металлические нарастания вместо привычного электронного бита.
- Более низкий регистр мелодии, длинные басовые ноты, меньше верхних арпеджио и больше пространства между атаками.
- Диффузная стереореверберация с затуханием вместо слышимого повторяющегося эха.
- Наследуемые органы управляют формантами, обертонами и колебаниями голоса. Сохранения и сравнение с предком работают как прежде.

## Музыка и эволюция

- Единый ритм для мелодии, баса, аккордов и ударных.
- Композиция из 16 тактов: тема, ответ, развитие и возвращение.
- Популяция из 18 музыкантов сохраняется между веками; три субкультуры наследуют музыкальные идеи.
- Меняются ноты, ритмические рисунки, гармония, тембры и характер исполнения.
- Сравнение потомка с предыдущим композитором кнопкой «Сравнить с предком».
- Плавная по структуре смена поколения: новая партитура вступает с начала фразы.
- Сохраняются ползунок настроения, культурные скачки, вымирания, запись WAV и автопрогресс +100 лет за реальный час.
- Сохранения предыдущей версии переносятся автоматически. История хранится в браузере на конкретном устройстве; пропущенные часы обрабатываются при следующем запуске.

Эволюция работает как алгоритм отбора и мутаций. Оценки «слушателей», «фанатов» и «критиков» вычисляет модель правил; это не отзывы людей и не нейросеть, обученная на аудиозаписях.

## Проверка

Пройдены 14 автоматических проверок и сборка сайта. Проверены 2000 лет наследования, сохранения v2/v3, независимость эволюции от проигрывания, смена партитуры на границе фразы, пауза и запись PCM. Новый звук проверен на 44,1 / 48 / 96 кГц на протяжении всей формы из 16 тактов: конечный сигнал, ограниченные уровни и число голосов. Отдельно проверены затухание и сброс реверберации, изменение аудиосигнала при мутации органов и сохранение высоты резонансной струны. Проверки сборки подтверждают наличие всей цепочки модулей AudioWorklet.

Устаревшие проверки стартового шаблона приведены к интерфейсу синтезатора. Звук проверен программно; субъективную оценку тембров на слух даёт слушатель.

## Запуск

Требуется Node.js 22.13+ и npm.

```sh
npm ci
npm run dev
```

Синтезатор использует AudioWorklet: для звука нужен защищённый контекст HTTPS либо localhost. Обычный удалённый HTTP-адрес подходит только для просмотра интерфейса.

```sh
node --test tests/zorg-music.test.mjs tests/zorg-timbres.test.mjs
npm run build
```

Унаследованные скрипты установки и сборки рассчитаны на Linux и утилиты GNU; на Windows для них нужен WSL.

## Основные файлы

- `app/page.tsx` — интерфейс, управление воспроизведением, сохранение истории и WAV.
- `public/alien-processor.js` — популяция, отбор, наследование, мутации, перенос сохранений.
- `public/zorg-music.js` — партитура, единый пульс и оркестровка.
- `public/zorg-timbres.js` — резонансные инструменты, дыхание и стереопространство.
- `tests/zorg-music.test.mjs` — проверки музыки и эволюции.
- `tests/zorg-timbres.test.mjs` — проверки звукового движка.
- `VERSION.json` — дата, авторство версии и исходный коммит.
